# 2026-09-04 mystock 统一投资控制台（平台化 + 模拟交易 + 认证 + 浅色商务风）

## 背景 / 需求

老板反馈：原「投资智辩」独立单页 SPA 界面不好看、交互体感差，且**智能辩论只是 mystock 一个功能**。
要求把 `web/` 重构成 **mystock 统一投资控制台**（侧边导航 + 多模块），补齐两个缺口：**模拟交易**（否则组合全景是静态 yaml、失效）与**用户认证**。

## 老板拍板的决策

| 项 | 结论 |
|---|---|
| 第一版模块 | 组合全景 / 行业雷达 / 明日选股 / 模拟交易 / 投资智辩 + 登录 |
| 视觉 | 简洁浅色商务风（推翻深色） |
| 撮合 | 半仿真：初始 100 万虚拟资金、按现价即时成交、T+1、佣金万2.5 + 印花税千1（仅卖出） |
| 持仓来源 | 模拟账户**替代** portfolio.yaml；现有 yaml 持仓首次 init 作种子 |
| 用户 | 多用户，Mongo 数据带 `user_id` 隔离 |
| 认证 | 复用新浪内部 CAS SSO（app.py 的 CAS_VALIDATE_URL/CAS_LOGIN_URL），user_id = 邮箱前缀 |
| 辩论模型 | wecode 换 deepseek-v4-flash（config.json `env.ANTHROPIC_MODEL`），实时辩论提速 |

## 改了什么

### 后端
- **新建 `scripts/sim_trade.py`**：模拟交易撮合引擎。
  - Mongo 新增 collection：`sim_accounts` / `sim_positions` / `sim_trades`（均带 user_id）。
  - `place_order` 按实时价成交；买入加权平均成本、当日记 `available_qty=0`（T+1，`pending_date` 跨自然日后解锁）；卖出校验可卖数量、扣佣金+印花税；**卖出归零用 `closed=True` 标记，遵守 CLAUDE.md 禁 delete**。
  - `get_account` 补实时价/市值/盈亏；`get_trades` 流水；`search_stocks` 复用 `stock_basic_info`（code 前缀/name 模糊）。
  - `sync_to_yaml`：下单后把 Mongo 投影写回 `data/portfolio.yaml`（account.cash + positions），供 review() 出组合全景——单一真相源在 Mongo，yaml 仅投影，`portfolio_strategy.py` 零改动。
- **重写 `scripts/api_server.py`**：单端口 FastAPI = API + 静态 serve `web/dist`。
  - 新增端点：`/api/auth/config`、`/api/auth/validate`（CAS 代理+GB2312 解码+XML 解析）、`/api/auth/dev-login`（DEV_USER 模式）、`/api/trade/account|order|trades`、`/api/portfolio`(+refresh, 3min 缓存)、`/api/sector`、`/api/buyplan`、`/api/stock/search`。
  - 保留辩论端点 `/api/debate`、`/api/data/{code}`、`/api/refine`、`/api/demo`、`/api/health`。
  - 登录态 = 自签 session token（内存，12h），`Authorization: Bearer` 注入 user_id；`DEV_USER` 非空则跳过 CAS（本地联调）。
  - SPA 回退：非 `/api` GET 一律回退 `index.html`，子路由刷新不 404。
- **`/root/.wecode/wecode-cli/config.json`**：`ANTHROPIC_MODEL` → `deepseek-v4-flash`。

### 前端（web/ 整体重构，Vite+React18+react-router-dom v7）
- `main.jsx` 挂 `BrowserRouter`；`App.jsx` = 路由壳 + `RequireAuth`（未登录 → /login）。
- `components/Layout.jsx`：左侧固定导航（总览/行情·选股/交易/深度研究 五入口 + 退出登录），顶部 topbar。
- `pages/`：`LoginPage`（DEV_USER 时显「开发模式登录」按钮，否则跳 CAS 后回跳 `/login?ticket=` 调 validate）、`PortfolioPage`（统计卡+目标 banner+可展开「七维决策卡」持仓明细+行业暴露+观察池+告警）、`SectorPage`（动量热力 Top10 表 + 苏醒雷达 Top5 含五维细节）、`BuyPlanPage`（漏斗 + α评分候选表）、`TradePage`（账户统计+下单面板（买入/卖出、搜索、费用试算、T+1 提示）+持仓表快捷买卖+成交流水）、`DebatePage`（收编原三流派辩论，功能不变）。
- `components/StockSearch.jsx`：防抖搜索下拉，交易/其他模块共用。
- `src/api.js`：token 自动注入；BASE 用 `window.location.origin` 拼绝对地址（浏览器与 Node 冒烟兼容）。
- `styles.css`：**浅色商务风重写**（保留原 CSS 变量名 → 既有辩论组件类名自动适配；新增控制台布局/卡片/表格/条形/标签全套）。A股语义色：红涨绿跌。
- `index.html` 标题更新；新增 `web/.gitignore`（node_modules/dist/smoke bundle）。

## 改了什么
### 后端（scripts/sim_trade.py）
- 新增观察池 Mongo collection **`sim_watchlist`**（带 user_id；移除用 `active:false` 软删，遵守禁 delete 守则；索引 `sim_watch_user_code`）。
- `get_watchlist` / `add_watchlist`（幂等：已在池→更新 thesis；曾移除→重新激活；从 stock_basic_info 自动带 name/industry/入池参考价）/ `remove_watchlist`。

- 变更后失效 `_portfolio_cache` 并投影 yaml。

### 前端
- `api.js`：加 getWatchlist/addWatchlist/removeWatchlist/updatePosition。
