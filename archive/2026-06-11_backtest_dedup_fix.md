# 2026-06-11 回测去重修复

## 改了什么
`scripts/backtest_engine.py` — `_simulate_trades` 和 `run` 方法增加持仓去重。

## 为什么改
回测每天对 buy_plan 输出的候选股票全部开仓，但不检查是否已持有同只股票。
导致同一天/连续几天对同一只股票重复买入（如中信建投被买14次），交易笔数虚高。

## 怎么改
- `_simulate_trades` 增加 `held_codes` 参数，已持仓跳过
- `run()` 维护 `held_codes` 集合，开仓时加入
- 开仓后不再对同一 code 开新仓

## 验证
修复前: 314笔, 盈亏比1.77
修复后: 18笔, 盈亏比1.28, 胜率61.1%
