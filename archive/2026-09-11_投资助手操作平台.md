# 投资助手「操作平台」

## 改了什么

投资助手从**只读分析师**升级为**能代替用户操作整个模拟盘平台的 agent**。用户下达操作指令 → 助手代替用户执行 → 报回结果（对话即授权，不做「建议→点确认」的中间步骤）。

### 1. 新建 `scripts/assistant_action.py`（操作 helper，镜像 `assistant_evidence.py` 取数范式）

- 子命令：`place_order` / `update_position` / `add_watchlist` / `remove_watchlist` / `run_review` / `account`（只读）。
- **用户隔离的构造性保证**：`user_id` 永远从 `--session` 经 `debate_session.get_session()` 解析，agent 只持有 session_id，拿不到、也传不进别人的 user_id。
- 每笔写操作 + `run_review` 落审计集合 `sim_agent_operations`（只 insert，遵守禁删）。
- 参数软校验（quantity>0、side∈buy/sell、类型合法），失败返回清晰中文错误让 agent 转述，不硬拦。
- 缺 pymongo 时 re-exec 到项目 venv（照抄 `assistant_evidence.py` 的范式）。
- 无硬护栏：T+1、浮亏等只作「软提醒」输出，不阻止执行。

### 2. `scripts/debate_session.py`（prompt 注入）

- `run_debate_turn` 组 prompt 前定义 `action_helper` + `action_block`（操作命令块）。
- **deep 模式**（原已有【会话ID】+【取数助手】）：新增【操作助手】块。
- **normal 模式**（原先**没有**【会话ID】）：补齐【会话ID】+【操作助手】+ 能力清单；把「不给出超出能力的确定性买卖指令」改为「用户明确下达操作指令才执行、绝不自主交易、护栏只提醒不硬拦」。

### 3. `skills/assistant/agent.md`（agent 行为指引）

- 核心原则新增「能替用户操作平台」；输入模板补【操作助手】块。
- 新增「操作能力」段：能力清单（下单/卖出、设止损止盈、加/移观察池、跑复盘、查账户、做分析）+ 操作指引（明确指令即执行、参数含糊追问一次、绝不自主交易、护栏只是提醒、禁止绕过 helper）+ 何时执行 vs 何时只建议对照表。
- 输出约束「不下单边买卖指令」改为「用户明确要求操作才执行，只是问看法不硬下指令」。

### 4. `web/src/pages/ResearchPage.jsx`（能力引导 UI）

- 输入框上方新增「我可以：」能力 chip 排（查账户/买股票/卖股票/设止损/加观察池/跑复盘），点击把模板指令填入输入框并聚焦——让用户一眼知道能指使助手干嘛。
- 空状态提示补「还能替你操作模拟盘」。

## 为什么

老板要投资助手「不止局限于分析，能替我操作整个平台」。前提约束（老板原话）：

1. **用户隔离是最大前提**——靠构造性保证（helper 从 session 解析 user_id），不靠 agent 自觉。
2. **护栏不是硬约束**——金额/次数上限只做提醒建议，一切以用户操作为主。
3. **自动粒度 = AI 代替用户做操作**——用户下达指令，助手直接执行并报结果。

复用现成范式：`assistant_evidence.py`（取数 helper 的 session→user_id + venv re-exec + stdout）+ `sim_trade.*`（已 user_id 隔离的 4 个写操作 + get_account/get_watchlist）。

## 影响面 / 复盘

- 纯增量：新增 1 个 helper 文件、1 个审计集合；改 3 个既有文件（debate_session.py 只加 prompt 块、agent.md 加指引、ResearchPage.jsx 加 chip）。
- 无破坏性改动：`sim_trade` 未动，前端既有渲染/接口未改。
- 残余风险（诚实说明）：agent 有 Bash 权限，理论上可绕过 helper 直接 `import sim_trade` 写库；当前靠「prompt 指引 + 模拟盘低风险」兜底，如需构造性杜绝，后续给 wecode 加 `--allowedTools` 收紧工具面（本期不做）。
- 本期不做（follow-up）：硬护栏（老板明确不要）；跑脚本异步化（radar/buy_plan/precompute 走任务队列，本期 `run_review` 先同步跑）。
