# 投资助手 deep 模式降本提速 + 子代理结论可追溯

## 改了什么

### 第一批（降本提速，纯后端）
1. `scripts/debate_session.py`
   - 新增 `EVIDENCE_MAX_CHARS` 常量（默认 12000，env 可调）。
   - 新增 `_safe_dumps(obj, max_chars)`：序列化为合法 JSON，超限逐项贪心截断
     —— 修复原 `json.dumps(data)[:12000]` 硬截断成非法 JSON 的 bug。
   - 重构 `_evidence_text` → 拆出 `_common_parts`（数据截至/自检/持仓/报告，只算一次）。
   - 新增 `_slice_evidence()`：把底座按「价值/成长/趋势/风险」四视角切片，
     每份只含该视角需要的字段（趋势信号只给趋势视角；风险视角只取回撤/波动/支撑压力；
     去掉 trend_signal 内嵌的冗余 llm_context）。
   - 新增 `_deep_evidence_text()`：deep prompt 用切片版底座，主代理按视角转发。
   - `create_session` 的 `web` 默认 True → False。
2. `scripts/api_server.py`：`DebateSessionCreate`/`DebateMessageCreate` 的 `web` 默认 True → False。
3. `web/src/pages/ResearchPage.jsx`：深度分析「联网」开关默认 false（默认用数据底座，更快更省）。

### 第二批（可追溯，动 skills）
4. `skills/assistant/value_view.md`（新建）：精简价值视角（~40 行），替代原先 21KB 的
   `stock_value_analyse/agent.md`（后者是完整 DCF 11 维 skill，deep 里价值视角用不上）。
5. `skills/assistant/agent.md`
   - Step 1 A：明确每个子代理只传对应【X视角数据】切片 + 输出 ≤300 字结构化结论（观点/依据/分歧）。
   - Step 2：要求主代理用引用块摘录各视角结论原文（≤150 字/视角），用户可回查原始判断。
   - Step 0.5：修正「原样传给每个子代理」的旧表述。

## 为什么改

deep 模式原先 4 个子代理各吃同一份 ~12KB 全量底座 + 主代理 1 份 = 5×12KB≈60KB 重复输入，
且硬截断会产出非法 JSON。实测宁德时代底座 13.8KB，其中 trend_signal 6KB、llm_context 4.8KB，
大部分只被一个视角用到。切片后四视角合计 ~18KB（省 70%），且每份子代理 prompt 更短 → 更快。
联网默认关则去掉 deep 最大的延迟/token 来源（联网搜索），底座已足够全。

可追溯性：原先 deep 只保留主代理 wecode session，子代理各自思考过程丢失；
现在要求主代理在汇总里引用各视角结论原文，用户能回查每个视角的原始判断。

## 怎么验证

- `py_compile` 全部通过。
- `_safe_dumps` 在 12000/4000/2000 字符预算下均产出合法 JSON。
- 实测切片：value 2320 / growth 3579 / trend 7435 / risk 4570 字符，合计 17904（vs 60000，省 70%）。
- `_deep_evidence_text` 四份切片 JSON 均合法。
- `_evidence_is_stale` 6 用例 + `_slice_evidence` 边界（缺失字段 .get 兜底）走查通过。
- **端到端真实跑**（一次性 user_id `smoke_deep_20260911`，宁德时代 deep 分析）：
  耗时 136s，REPLY 顶部出现「数据截至 / 联网开关关闭」，`### 各视角判断` 用 `>` 引用块
  摘录了价值/成长/趋势/风险四视角原文，切片数据各归其位（价值用估值/回购、趋势用均线/RSI、
  风险用回撤/支撑位/两融），归档 `assistant_deep_300750_2026-09-11.md` 正常生成。
  主代理还主动标注「RSI14=68.41 与 KDJ 超卖背离，存疑」，数据自检机制生效。

## 局限 / 后续

- 趋势视角切片仍最大（7.4KB，因 trend_signal 是趋势视角核心数据，属合理保留）。
- 四因子 factor 在价值+成长重复一份（因子是整体叙事，拆碎破坏上下文，权衡后保留）。
