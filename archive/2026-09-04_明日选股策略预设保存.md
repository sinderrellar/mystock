# 明日选股：默认策略值对齐 v3 生效值 + 策略预设（按用户存数据库）

日期：2026-09-04

## 改了什么

在「分层漏斗可视化」基础上补两个诉求：

1. **默认值 = 系统原策略值**：面板初始化默认对齐当前 v3 实际生效口径，显式命名为「默认策略（系统）」预设。
2. **策略值组合保存（按用户存数据库）**：用户可把当前 5 层参数组合存为命名预设，随 user_id 存 MongoDB，换设备可读；支持保存（同名覆盖）/加载/删除。

### 后端

- 新增 `scripts/buyplan_presets.py`：MongoDB 持久化模块，collection `buyplan_presets`，user_id 隔离，幂等建索引 `(user_id, name)`。
  - `list_presets(user_id)`：返回 active 项（按名称排序）。
  - `save_preset(user_id, name, filters)`：upsert（同名覆盖），空名/超 50 字报错。
  - `remove_preset(user_id, name)`：**软删** `active=False`（遵守 CLAUDE.md「禁止 delete/remove」守则，不物理删除）。
- `scripts/api_server.py`：新增 3 个端点（复用 `_get_current_user` 鉴权 + `_jsonable` 序列化）：
  - `GET  /api/buyplan/presets` → `{items:[{name,filters,saved_at}]}`
  - `POST /api/buyplan/presets` → `{name, filters}` 保存
  - `POST /api/buyplan/presets/remove` → `{name}` 软删
  - 新增 Pydantic 模型 `BuyPlanPresetSaveRequest` / `BuyPlanPresetRemoveRequest`。

### 前端

- `web/src/api.js`：新增 `getBuyPlanPresets` / `saveBuyPlanPreset` / `removeBuyPlanPreset`。
- `web/src/buyplan.js`：删掉上一版 localStorage 预设函数，保留 `BUILTIN_PRESET_NAME` 常量与 `DEFAULT_FILTERS`。
- `web/src/pages/BuyPlanPage.jsx`：
  - 页面顶部「策略预设」条：下拉选预设（默认策略 + 用户预设 + 自定义态）、「保存当前为预设」（`window.prompt` 命名）、「删除此预设」（仅用户预设可删），busy 态禁用按钮 + 内联 `presetMsg` 反馈成败。
  - 预设从后端加载/保存/删除（挂载时 `getBuyPlanPresets` 拉一次）；任一控件改动 → `activePreset` 置空（「自定义（未保存）」）。
  - 加载用户预设时，旧预设若未存 alpha 权重则回落当前市场 regime 权重，避免滑杆显示 0。
- `web/src/styles.css`：`.preset-bar` 样式（上版已加，本次未变）。

## 为什么这样改

- 老板明确要「存数据库，按用户存、按用户加载」：预设是跨设备的用户级配置，localStorage 换设备/清缓存会丢，故迁到 MongoDB（复用 `sim_trade` 同款 `_get_mongo()` 配置）。
- 删除用**软删**而非物理 delete：CLAUDE.md 禁止数据库 delete/remove，且物理删不可逆；软删后 `list` 过滤掉即等效「删除」，数据仍可审计。
- 默认策略值：老板选「当前 v3 实际生效值」（海选 50亿/5000万/PE0-200、cycle≥0.20、market regime 权重 + top15 + 已持仓降权、其余不筛）。

## 怎么验证

- `venv/bin/python -m py_compile scripts/api_server.py scripts/buyplan_presets.py` 通过。
- `cd web && npm run build` 通过（312 modules，无语法/JSX 错误）。
- Mongo 直测（一次性 user_id `__claude_test_preset_0001__`）：`list` 空 → `save` → 同名覆盖 → `list` 返回覆盖后的 filters → `remove` 软删 → `list` 空，全链路正确。测试项已软删（active=False），不污染真实用户。

## 已知边界

- 弱市下 v3 有更严的 `weak_min_cycle=0.50`，默认滑杆仍用 0.20、未按 regime 自动切；页头已显示当前 regime，可手动上调周期分下限。
- 预设删除为软删，集合里会积累历史 active=False 文档（可审计，不占用户列表）。
- 预设名称长度限 50 字；同名保存即覆盖（无二次确认）。
