# 持仓「按用户隔离」投影改造 —— 修复跨用户种子污染（宁德时代事件）

## 背景 / 需求（老板 2026-09-07）

老板反馈两件事：①「宁德时代的持仓怎么给我加进来了？？给我去掉」；②「现在的持仓数据没有按人头分，还是多人共享的」。经排查，宁德时代是「凭空」被种进 liuyu20 账户的，根因是持仓投影文件 `data/portfolio.yaml` 是**单例共享文件**，与按 `user_id` 隔离的真相源 `sim_positions` 对不上。老板拍板采用「按用户独立投影文件」方案。

## 根因（已坐实，附证据）

- `sim_trade.sync_to_yaml(user_id)` 把**单个用户**的持仓覆盖写进共享 `data/portfolio.yaml`。
- `sim_trade.init_user(user_id)` 在该用户无未平持仓时，从**共享 yaml** 给其「播种」持仓。
- 污染链：某同事/测试下单 → `sync_to_yaml` 投影到共享 yaml → liuyu20 空账户下次登录 → `init_user` 从共享 yaml 种入宁德时代（走「播种」非「下单」，**现金未扣、无成交记录**，故「凭空出现」）。

Mongo 证据：`liuyu20` 有 300750 持仓但 `sim_trades` 无对应成交；`zhongyue3` 有 300750 且**有成交**（真买过）；`zhizhong` 与若干 `ut_*`/`smoke_verify` 测试号同被种。liuyu20 现金仍 100 万（播种不扣款）。

## 改了什么

### 1. `scripts/sim_trade.py`

- 新增 `user_portfolio_path(user_id)`：按用户隔离的投影文件路径 `data/portfolio_<user_id>.yaml`，user_id 做文件名安全化（`re.sub(r"[^0-9A-Za-z_.-]", "_")`）防路径穿越。
- `sync_to_yaml(user_id)`：写入 `user_portfolio_path(user_id)` 而非共享 `DEFAULT_PORTFOLIO`；首次投影时从离线手动 `portfolio.yaml` 继承 account 约束（target/risk_profile）。
- `init_user(user_id)`：**删除「从共享 yaml 播种」逻辑**，仅 `get_or_create_account`（幂等建 100 万空账户）。新用户一律空仓起，真实持仓经下单/观察池各自建立。

### 2. `scripts/api_server.py`

- `_run_review(portfolio_path=None)`：透传路径给 `PortfolioStrategy(portfolio_path=...)`。
- `_get_portfolio(user_id)`：`sync_to_yaml(user_id)` 后 `_run_review(sim_trade.user_portfolio_path(user_id))`，组合全景读本用户投影。

### 3. `scripts/research_engine.py`（verdict 综合研判）

- `run_verdict` 里有 user_id 时，`PortfolioStrategy(portfolio_path=sim_trade.user_portfolio_path(user_id))` 读本用户投影，不再读共享 yaml。

## 为什么这样改

- 真相源 `sim_positions` 本就按 `user_id` 隔离，问题只在「共享投影文件」这一层；把投影改为 per-user 即可最小改动消除跨用户污染，且 `review()` 已经支持 `portfolio_path` 参数（`PortfolioStrategy.__init__` 第 56 行），无需重构其 700 行 yaml 耦合。
- 顺带修复 `scripts/sim_trade.py` 的 `__main__` 自测（`SIM_USER=test_user` 下单后 `sync_to_yaml` 现写 `portfolio_test_user.yaml`，不再污染共享文件）。
- 离线手动组合 `data/portfolio.yaml` 从此**不再被 web 模拟交易流程触碰**（buy_plan/sector_radar/dashboard/debate_engine/portfolio_controller 等 CLI 工具继续读它，语义回归「手动离线组合」）。

## 怎么验证

1. `py_compile` 三个改动文件通过。
2. `user_portfolio_path('liuyu20')`=`data/portfolio_liuyu20.yaml`；`../evil/x`、`a@b.com` 均被安全化为合法文件名。
3. `sync_to_yaml('liuyu20')` 写 per-user 空仓文件（positions=[]，cash=100 万，account.target 约束保留），共享 `portfolio.yaml` **md5 前后不变**（未被 web 流程改动）。
4. 双向隔离：`sync_to_yaml('liuyu20')`→空；`sync_to_yaml('zhongyue3')`→[宁德时代]（该用户真买过）。两文件互不串号。
5. `init_user('ut_no_seed_probe')` 后新用户持仓数=0（不再播种）。
6. `PortfolioStrategy(portfolio_path='data/portfolio_liuyu20.yaml')` 正确加载空仓（无 EXAMPLE 兜底）。
7. 后端重启（PID 26649 → 23118）后 `/api/health` 200、`dev_user=""`（CAS 模式）。
