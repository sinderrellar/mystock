# 优化 CLAUDE.md 阶段3：研究触发前先查 memory

## 改了什么

在阶段3（定性深化）之前新增 **3.0 查 memory** 步骤，避免重复触发已有研究成果。

核心变更：
- 研究触发前必须先扫 `memory/` 目录，核对目标+类型是否有新鲜研究
- 定义有效期：investment/industry 14天，valuation 30天，筹码分析 7天
- 在有效期内的直接用，过期的标注后更新，缺失的正常触发
- 新增 3.1（触发条件表，增加 memory key 列）和 3.2（研究完成后归档到 memory）
- 保留原有的触发条件表和所有 Skill 调用逻辑

## 为什么改

老板指出 review 时应该先看 memory 里有没有已有研究，避免每次都重新跑 Agent。

## 怎么验证

下次跑 review 时，会先列出 memory 中匹配的已有研究，标注有效期状态，只对过期/缺失的触发新研究。
