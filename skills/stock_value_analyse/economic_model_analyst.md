## 必须分析的指标

### 一、盈利能力指标（近5年）
| 指标 | 说明 |
|------|------|
| **ROE（净资产收益率）** | 净利润 / 股东权益 |
| **销售净利率** | 净利润 / 营业收入 |
| **销售毛利率** | (营业收入 - 营业成本) / 营业收入 |

### 二、成长能力指标（近5年）
| 指标 | 说明 |
|------|------|
| **营业收入增长率** | (本期营业收入 - 上期营业收入) / 上期营业收入 |
| **净利润增长率** | (本期净利润 - 上期净利润) / 上期净利润 |

### 三、营运能力指标（近5年）
| 指标 | 说明 |
|------|------|
| **资产周转率** | 营业收入 / 平均总资产 |

### 四、偿债能力指标（近5年）
| 指标 | 说明 |
|------|------|
| **流动比率** | 流动资产 / 流动负债 |
| **资产负债率** | 总负债 / 总资产 |

### 五、当前估值指标
| 指标 | 说明 |
|------|------|
| **市盈率(PE-TTM)** | 当前股价 / 最近12个月每股收益 |
| **市净率(PB-TTM)** | 当前股价 / 最近每股净资产 |

### 六、总股本数据（用于DCF估值）
| 指标 | 说明 |
|------|------|
| **总股本** | 股份总数（亿股），用于计算市值比 |
| **流通股本** | 流通股份数（亿股） |

## 数据处理流程

### 第一步：从workspace读取数据

读取以下文件获取预获取的数据：
- 公司财务数据（营业收入、净利润、资产、负债等）
- 股票信息（股价、总股本、流通股本）
- 估值数据（市盈率、市净率）

### 第二步：计算衍生指标

根据获取的基础数据，计算以下衍生指标：

```
盈利能力：
- 销售净利率 = 净利润 / 营业收入
- 销售毛利率 = (营业收入 - 营业成本) / 营业收入

成长能力：
- 营业收入增长率 = (本期营业收入 - 上期营业收入) / 上期营业收入
- 净利润增长率 = (本期净利润 - 上期净利润) / 上期净利润

营运能力：
- 资产周转率 = 营业收入 / 平均总资产

偿债能力：
- 流动比率 = 流动资产 / 流动负债
```

### 第四步：绘制趋势图

**必须使用Python绘制以下图表：**

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.use('Agg')
# 设置中文字体
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

# 数据（示例，需替换为实际数据）
years = ['2020', '2021', '2022', '2023', '2024']

# 创建2x2子图
fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle('[公司名] 经济模型指标趋势图', fontsize=16, fontweight='bold')

# 1. 盈利能力指标（ROE、销售净利率、销售毛利率）
ax1 = axes[0, 0]
roe_data = [15.2, 16.8, 18.5, 17.2, 19.1]  # 替换为实际数据
net_profit_margin = [12.5, 13.2, 14.1, 13.8, 14.5]  # 销售净利率
gross_margin = [45.2, 46.5, 47.8, 47.2, 48.1]  # 销售毛利率
ax1.plot(years, roe_data, 'b-o', linewidth=2, markersize=6, label='ROE')
ax1.plot(years, net_profit_margin, 'g-s', linewidth=2, markersize=6, label='销售净利率')
ax1.plot(years, gross_margin, 'r-^', linewidth=2, markersize=6, label='销售毛利率')
ax1.set_title('盈利能力指标', fontsize=12)
ax1.set_ylabel('%')
ax1.legend(loc='best')
ax1.grid(True, alpha=0.3)

# 2. 成长能力指标（营业收入增长率、净利润增长率）
ax2 = axes[0, 1]
revenue_growth = [8.5, 12.3, 15.2, 10.5, 14.8]  # 营业收入增长率
profit_growth = [10.2, 15.8, 18.5, 8.2, 16.5]  # 净利润增长率
ax2.plot(years, revenue_growth, 'b-o', linewidth=2, markersize=6, label='营业收入增长率')
ax2.plot(years, profit_growth, 'g-s', linewidth=2, markersize=6, label='净利润增长率')
ax2.axhline(y=0, color='black', linestyle='--', linewidth=0.5)
ax2.set_title('成长能力指标', fontsize=12)
ax2.set_ylabel('%')
ax2.legend(loc='best')
ax2.grid(True, alpha=0.3)

# 3. 营运能力指标（资产周转率）
ax3 = axes[1, 0]
asset_turnover = [0.85, 0.92, 0.98, 0.95, 1.02]  # 资产周转率
ax3.plot(years, asset_turnover, 'purple', marker='o', linewidth=2, markersize=8)
ax3.fill_between(years, asset_turnover, alpha=0.3, color='purple')
ax3.set_title('营运能力指标 - 资产周转率', fontsize=12)
ax3.set_ylabel('次')
ax3.grid(True, alpha=0.3)
for i, v in enumerate(asset_turnover):
    ax3.annotate(f'{v}', (years[i], v), textcoords="offset points", xytext=(0,10), ha='center')

# 4. 偿债能力指标（流动比率、资产负债率）
ax4 = axes[1, 1]
current_ratio = [1.8, 1.9, 2.0, 1.85, 1.95]  # 流动比率
debt_ratio = [45.2, 43.5, 42.1, 44.8, 43.2]  # 资产负债率
ax4_twin = ax4.twinx()
line1 = ax4.plot(years, current_ratio, 'b-o', linewidth=2, markersize=6, label='流动比率')
line2 = ax4_twin.plot(years, debt_ratio, 'r-s', linewidth=2, markersize=6, label='资产负债率')
ax4.set_title('偿债能力指标', fontsize=12)
ax4.set_ylabel('流动比率 (倍)', color='blue')
ax4_twin.set_ylabel('资产负债率 (%)', color='red')
ax4.axhline(y=1, color='blue', linestyle='--', linewidth=0.5, alpha=0.5)
ax4.grid(True, alpha=0.3)
lines = line1 + line2
labels = [l.get_label() for l in lines]
ax4.legend(lines, labels, loc='best')

plt.tight_layout()
plt.savefig('/workspace/charts/[公司名]_economic_model.png', dpi=150, bbox_inches='tight')
plt.close()
print("图表已保存")
```
