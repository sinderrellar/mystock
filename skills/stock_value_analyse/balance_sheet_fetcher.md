## 数据来源质量评估框架

### 来源层级定义

| 层级 | 类型 | 示例 | 置信度 |
|------|------|------|--------|
| **Tier 1** | 官方/监管机构 | 巨潮资讯网、证监会、交易所官网 | 高 |
| **Tier 2** | 金融数据提供商 | 东方财富、同花顺、新浪财经 | 高 |
| **Tier 3** | 研究/咨询公司 | 券商研究报告、咨询机构 | 中 |
| **Tier 4** | 行业来源 | 行业协会、专业网站 | 中 |
| **Tier 5** | 新闻/媒体 | 新闻报道、媒体文章 | 低 |

### URL可访问性验证要求

**获取数据前，必须验证数据源URL可访问：**

1. 优先使用官方发布页面（如巨潮资讯网年报）
2. 验证目标网页可正常加载
3. 确认数据更新时间（优先最新数据）
4. 记录实际访问的URL地址

### 置信度评估标准

| 置信度 | 评级标准 |
|--------|----------|
| **高** | 来自Tier 1-2来源，数据经交叉验证一致 |
| **中** | 来自Tier 2-3来源，数据存在轻微差异但可接受 |
| **低** | 来自Tier 4-5来源，或多源数据差异超过阈值 |

### 数据点验证要求

**每个数据点必须记录以下信息：**

- 原始来源：具体URL和页面名称
- 置信度评级：高/中/低
- 验证状态：已验证/待核实/已修正

**低置信度数据处理流程：**

```
1. 发现低置信度数据（如来自Tier 4-5来源）
2. 尝试从更高层级来源重新获取
3. 如Tier 1-2来源无数据，进行多源交叉验证
4. 最终输出尽量避免低置信度数据
```

## 职责

此子代理负责获取A股上市公司的资产负债表数据。需要获取过去3年的年度年报数据以及当年所有季度的季度报告数据。

## 数据源优先级规则

**重要：严格遵循以下数据源优先级，优先使用Tier 1-2级来源！**

| 优先级 | 数据源 | 层级 | 说明 |
|--------|--------|------|------|
| 1 | **巨潮资讯网** | Tier 1 | 证监会指定披露网站，官方权威 |
| 2 | **东方财富** | Tier 2 | 财务数据频道，数据权威性高 |
| 3 | **新浪财经** | Tier 2 | 财务数据，可靠性高 |

## 数据获取要求

### 时间范围

- 过去3年年报数据：2023年、2024年、2025年
- 当年所有季度数据：2026年Q1、Q2（如有）
- 如有最新半年报，也需获取

### 资产负债表核心数据

#### 资产类

1. **流动资产**
   - 货币资金
   - 交易性金融资产
   - 应收票据
   - 应收账款
   - 预付款项
   - 其他应收款
   - 存货
   - 一年内到期的非流动资产
   - 其他流动资产

2. **非流动资产**
   - 可供出售金融资产
   - 持有至到期投资
   - 长期股权投资
   - 投资性房地产
   - 固定资产
   - 在建工程
   - 无形资产
   - 开发支出
   - 商誉
   - 长期待摊费用
   - 递延所得税资产
   - 其他非流动资产

#### 负债类

1. **流动负债**
   - 短期借款
   - 交易性金融负债
   - 应付票据
   - 应付账款
   - 预收款项
   - 应付职工薪酬
   - 应交税费
   - 其他应付款
   - 一年内到期的非流动负债
   - 其他流动负债

2. **非流动负债**
   - 长期借款
   - 应付债券
   - 长期应付款
   - 专项应付款
   - 预计负债
   - 递延所得税负债
   - 其他非流动负债

#### 所有者权益类

- 实收资本（或股本）
- 资本公积
- 减：库存股
- 其他综合收益
- 专项储备
- 盈余公积
- 未分配利润
- 归属于母公司所有者权益合计
- 少数股东权益

## 重要说明

1. **数据源优先级**：巨潮资讯网 > 东方财富 > 新浪财经
2. **来源层级**：优先使用Tier 1-2级来源
3. **数据完整性**：必须获取所有列出的资产负债表项目
4. **时间连续性**：确保3年年报和当年季度数据完整
5. **单位统一**：所有金额统一转换为亿元
6. **数据标注**：每项数据必须标注来源、URL、置信度和验证状态
7. **低置信度处理**：尽量避免低置信度数据，如遇低置信度需进行二次验证
8. **存入workspace**：`/workspace/company_data/[公司名]/balance_sheet.json`

## 使用场景

此代理主要用于：

- 获取资产规模数据用于公司规模分析
- 获取负债结构数据用于偿债能力分析
- 获取净资产数据用于账面价值计算
- 获取历史数据用于趋势分析
